```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\phase176_r3r16_public_connection\run.ps1 -DryRun
powershell -NoProfile -ExecutionPolicy Bypass -File .\phase176_r3r16_public_connection\run.ps1
```
