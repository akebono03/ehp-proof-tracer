# Phase 174 R3-R6-R3R1 — 作業ツリー限定ガード修正

## 目的

R3-R6-R3 のファイル全体 Git blob 一致判定は、修正対象外のローカル差分まで拒否していた。
本修正では、確認済み HEAD と **変更対象関数の AST**、およびモジュール先頭 import の一致を厳密に比較し、関数以外の既存差分をバイト単位で保持する。

## 追加するファイル・関数

追加位置: リポジトリ直下の新規 `phase174_r3_r6_r3r1_scoped_guard_fix/`。

- `patch.py`: `ScopedChange`（新規 dataclass 全体）、`git_blob_sha()`、`git_head_file()`、`normalize_text()`、`statement_ast()`、`preserve_original_lines()`、`inspect_scoped_change()`、`reviewed_changes()`、`write_atomically()`、`write_outputs()`、`main()`。
- `tests/test_patch.py`: `_repo()`、および5件の限定テスト。
- `run.ps1`: 新規スクリプト全文。

既存の `phase168_r3_27_typed_statement_projection.py` と `phase168_r3_5_model_renderer.py` の import は変更しない。既存の対象関数の変更後全文は、DryRun により `output/CODE_FULL_JA.md` と個別 `.py` に出力される。

## 安全条件

1. `develop` の HEAD がローカルと GitHub で一致すること。
2. `git show HEAD:path` の Git blob が監査済みの SHA であること。
3. 対象関数 AST と import AST が HEAD と一致し、パッチの anchor が一意であること。
4. 元のファイル行は削除・書換えせず、追加行だけを挿入すること。
5. その他の未コミット変更は内容を保持し、改変しないこと。
6. 関数自体に未確認の実質的変更があれば必ず中断すること。
