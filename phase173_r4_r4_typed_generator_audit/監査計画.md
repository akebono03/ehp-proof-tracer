# Phase 173 R4-R4 — 型付き生成元像監査

## 目的

R4-R3 で確認した抽象群構造の一致を、Toda Proposition 4.4 の具体的な同型写像の生成元対応と区別する。既存の $\pi_7^4$ の証明経路は変更せず、実行時に公開完成証明の回帰確認を行う。

対象は $i=7,8,9,10$ の $\pi_i^4$。$i=7$ は保護された比較対象、$i=8,9,10$ は新しい候補の型付き検査のみを行う。

同型の写像は

$$
\Phi_i(\alpha,\beta)=E\alpha+\nu_4\circ\beta,\quad
\pi_{i-1}^3\oplus\pi_i^7\cong\pi_i^4.
$$

## 安全条件

1. 既存の GitHub `develop` HEAD と確認済み BLOB を照合し、追跡済みファイルの変更を拒否する。
2. $\pi_{i-1}^3$、$\pi_i^7$ は DB の候補と明示する。先行 DB 採用は完成証明を意味しない。
3. $E(\nu'\circ\eta_6)$ と $E\nu'\circ E\eta_6$ の一致は、懸垂の合成に関する functoriality（関手性）の証明を必要とする。監査は期待される式の形を計算するだけで、ProofStep は生成しない。
4. Lemma 5.4 の出典検証と引用順序の調査を実施するが、これを新しい GIVEN として登録しない。
5. 完成証明の宣言、Web 表示の変更、全体 pytest の実行は行わない。
