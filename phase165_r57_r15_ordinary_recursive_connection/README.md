# Phase 165 R57-R15 — Ordinary On-Demand Proof Order

This package connects the existing on-demand recursive search to the ordinary typed group goal path when a reviewed, proof-order-only catalog is supplied. It does not install any unreviewed proof order, persist ProofSteps, or manufacture theorem premises. The normal Web path remains unresolved until reviewed proof-order metadata is available and attached to its query context. Run `run.ps1` from Windows PowerShell after extracting at the project root.
