# EHP Proof Tracer — Phase 174 R3-R5: finite cyclic extension

This package makes a **minimal, source-conditional** addition to the ordinary
backward proof search. It does not assert a completed proof of `pi_8^5`.

A validated `CyclicStructureStatement` is expanded to a typed index-two
injection, an independently proved earlier finite-cyclic group presentation,
and a separately inferred doubled-generator equality. The index-two injection
itself expands to an inferred zero-Delta statement and the **unregistered**
source obligation for Toda (4.8). No unreviewed literature assertion is
promoted to `GIVEN`.

The group-theoretic inference is general: if `A` is cyclic of **even** order
`m`, `f:A -> B` is injective with `[B:f(A)] = 2`, and `2b=f(a)` for a generator
`a`, then `B` is cyclic of order `2m` generated by `b`. The Toda (4.8) rule
checks the full even-dimensional source/target and Delta-index contract.
No group name, generator family, `n=5`, or `k=3` literal is present in the
production inference decision.

## Intentional remaining obligations

The cited general Toda (4.8) typed source is not yet registered, and the
specialized Toda (5.5) equality is not yet independently reconstructed as an
inference. Prior-result source precedence must also pass through the existing
proof engine. The implementation therefore establishes the *backward route*
from the named group's cyclic goal to the independently proved Delta-zero
subgoal, not final group completion.

The full test suite is deferred to Phase 174 closeout.
The focused regression suite also includes `tests/test_head_lineage.py` to
reject unknown branches, remote changes, and unreviewed commit differences.

## R3-R5 R2: Windows Git path quoting correction

The HEAD-lineage guard still requires the same exact seven changed files.
A Windows Git client may emit octal-escaped text for non-ASCII filenames
by default (`core.quotePath=true`). The guarded `git diff --name-only`
invocation now includes the per-command setting `-c core.quotePath=false`,
so the Japanese filename is decoded as literal UTF-8 before exact-set
comparison. The remote/local HEAD, commit ancestry, file list, Git blob,
worktree protection, and staged-file safety checks are unchanged.
The focused test uses an isolated temporary Git repository with a Japanese
filename to confirm this behavior without changing the project repository.
