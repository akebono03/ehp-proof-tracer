# Phase 170 R3-R8 — n=2 全登録範囲の監査

## 目的

R3-R7 により、辞書式順序 $(k,n)$ の先行 DB 結果と Toda (5.2) を使う共通証明生成が、少なくとも9件の対象で完成した。次段階は、`data/sphere.csv` に存在する $n=2$ の全ての明示行を検査し、**網羅性と未解決原因を事実で判定**すること。

## 数学上の適用範囲

Toda (5.2) の同型 $\eta_2\circ-:\pi_m^3\cong\pi_m^2$ は $m\geq3$ の範囲。$\pi_2^2$ はこの方法の範囲外である。また、型付き生成元の対応がデータ上で確認できない場合、同型が存在することだけを理由に、DB の個別表示生成元を証明済みにしない。

## 検証内容

各 $k$ に対し、DB 実在行、型付き目標、対応する先行 DB 群 $(n',k')=(3,k-1)$、辞書式順序、`search_group_from_registered_goal(n=2,k=k)`、Web `build_standard_web_group_proof_view(...)` のキーと Trust Boundary 通過の結果を記録する。全件検証のため、孤立した子プロセスを用い、1件が失敗しても他の $k$ を継続する。

`COMPLETE_AND_WEB_VERIFIED` と見なすのは、検索 `COMPLETE`、非空の ProofStep、未解決 Goal が0、Web の `generic-complete-proof`、`partial_result=False`、非空のステップと本文が揃う場合のみ。

## 変更範囲と完了条件

変更対象となる production ファイル、クラス、関数、既存テスト：**なし**。監査パッケージ `audit.py`・`run.ps1` と説明用文書のみ追加する。全体 pytest は実行しない。

実行成功と数学的完了は別々に記録する。`domain_gaps=0` かつすべての監査対象が含まれる場合のみ、**今回の DB 登録範囲での Web 完成証明の網羅性**を主張できる。未検証の将来登録データや DB に存在しない群には一般化しない。
