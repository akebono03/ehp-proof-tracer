# Phase 175 R4R14R3 — Binary Composition Audit

A read-only audit of the already implemented binary suspension rule and the missing bridge from a certified zero relation for a whole composition to a zero generator image. The archive contains no production patch and no mathematical GIVEN.

From the repository root, invoke `run.ps1 -DryRun` and then `run.ps1`. The run performs only focused pytest, with `--import-mode=importlib` to avoid duplicate test-module basenames. The audit records a JSON report in the Windows temporary directory.

Successful auditing does **not** mean that the target group has been proved. The next task is to review a minimal generic two-premise inference that uses an independently proved composite image and an independently proved zero relation for that **same whole composite**. It must not specialize to a particular generator or root group.
