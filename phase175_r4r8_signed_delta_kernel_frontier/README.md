It verifies the reviewed R4R7 Git lineage, source blob identities, the genuine completed R4R7 audit report, the printed signed identity, the typed EHP Delta–E window, and the shapes of earlier database group presentations.

For a hypothetical generator action `E(x) = z` and `E(y) = (N/m)z` from `Z{x} ⊕ Z/m{y}` onto `Z/N{z}`, the pure arithmetic kernel is `Z{(N/m)x - y}`. This algebraic calculation is **not** promoted to a verified proof step; the actual map actions and exactness must still be proved separately.

There are no new `GIVEN` statements, no new inference rules, no source or production modifications, no new public provider, no replay of completed prior proofs, and no claim that `pi_9^5` is complete.
