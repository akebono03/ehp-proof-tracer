# Phase 171 R2J-R4-R9-R18：位数4の3前提監査

## 背景

R17 で $H$ の2つの全射性、$\Delta=0$、$E$ の単射性、EHP 短完全列を独立に証明できた。一方、$|\pi_6^3|=4$ 以降は未解決である。2つの文献集合の ID は不一致だが、8つの検査対象の証明成否は一致した。

## 目的

既存の規則 $|B|=|A|\,|C|$ を追加し直さず、次の3つの実際の部分目標を再帰探索器で独立に検証する。

1. $\pi_5^2\cong\mathbb Z/2$ の既存の引用された結果。
2. $0\to\pi_5^2\to\pi_6^3\to\pi_6^5\to0$ の型付き短完全列。
3. $\pi_6^5\cong\mathbb Z/2$ の引用を持つ特殊化。

3前提がすべて証明された場合に限り、既存の `find_inference_matches_for_rule` で位数4の推論が一致するかを検査する。検査用に作った ProofStep を通常探索に渡してはならない。

## 判定と安全性

- `CARDINALITY_PREMISE_NOT_INDEPENDENTLY_PROVED`：3前提の少なくとも1つが共通探索器で未証明。
- `CARDINALITY_MATCHER_REJECTS_PROVED_PREMISES`：3前提は証明できたが、推論規則の照合が0件。
- `CARDINALITY_MATCH_AMBIGUOUS_OR_UNOBSERVED`：照合が複数または未観測。
- `CARDINALITY_VALID_PREMISES_BUT_RECURSIVE_PATH_UNRESOLVED`：独立には組み合わせ可能でも、共通探索器では位数4が未解決。
- `CARDINALITY_INDEPENDENTLY_PROVED`：位数4も単独で証明できた。Root の完成は別途検査する。

引用文献は実際の公開 context と R17 の監査用 context を分けて検査し、元の R17 レポートとの一致を要求する。`GIVEN` の証明葉は出典、時系列、型付き同一性を再検証する。既存ソース変更0件、新規 `GIVEN` 0件、完成した証明木の輸入なし、Trust Boundary 不変とする。全体 pytest は Phase 終了時まで行わない。
