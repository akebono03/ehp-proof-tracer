1. R4-R8 の完成証明を再構成し、`INFERENCE` と登録された目標の完全一致を確認する。
2. 共通 Provider に R4-R8 の推論規則と前提が完全一致する選択肢があるか確認する。
3. 公開 `search_group_from_registered_goal(n=3,k=3)` を別に実行し、`COMPLETE` / `PARTIAL` / `SEARCH_FAILED` を記録する。
4. 公開 `build_standard_web_group_proof_view(n=3,k=3,mode='narrative',citation_source='model')` を普通に呼び、信頼境界を通った完成表示か、未完成表示か、例外かを分けて記録する。
