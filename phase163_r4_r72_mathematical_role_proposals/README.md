# Phase 163 R4-R72 — Source-grounded role proposals

This read-only helper creates explicit editorial proposals for selected candidate passages and retains the other 203 candidates as unreviewed. It reads the R71 JSON report. It does not assert mathematical correctness, verify the original printed edition, register statement IDs, change production code, or enable proof search.

Run from the project root using `powershell -ExecutionPolicy Bypass -File .\phase163_r4_r72_mathematical_role_proposals\run.ps1`.

Outputs are written to `phase163_r4_r72_output/role_proposals.json`, `role_proposals.csv`, and `report.md`. Run the complete pytest suite only when Phase 163 ends.
