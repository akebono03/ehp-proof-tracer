# Phase 173 R4-R3 — 一般化の前提監査

## 目的

R4-R2 で得た公開探索7群の結果を前提として、Toda (5.2) と Toda (5.6) を一般化する際に必要な **入力群・先行結果の利用順・型付き生成元対応** を切り分ける。

## 対象

- Toda (5.2)：$\pi_i^3 \to \pi_i^2$（$i=7,8,9,10$）と、逆向き利用を検討する際の DB prior 順序。
- Toda (5.6)：$\pi_{i-1}^3\oplus\pi_i^7\cong\pi_i^4$（$i=7,8,9,10$）の入力群の有無と抽象群構造の整合。
- 公開 worker：$\pi_7^7,\pi_8^7,\pi_9^7,\pi_{10}^7$ の現状確認。
- 対象追加：$\pi_{10}^4$。これは R4-R2 の7群監査には含まれていなかった。

## 禁止事項と評価の境界

1. DB の群構造候補を証明済み定理として格上げしない。
2. `abstract_structure_compatible` は結論の数学的証明を意味しない。
3. Toda (5.2) の同型を逆向きに使う場合、前提の証明が元の $\pi_i^3$ に依存していないかを別途検査する。
4. Toda (5.6) の生成元の像、懸垂と合成の交換、零群の扱いは独立した型付き証明を要する。
5. R4-R1 の公開完成経路は変更しない。全体 pytest は Phase 173 最終ゲートのみ。

## 判定

`audit.json` に source group の状態、DB prior の適格性、群構造の比較および固定規則の対象限定が記録される。そこから次の最小実装範囲を決める。推論の一般化と Web 完成の宣言は本監査には含めない。
