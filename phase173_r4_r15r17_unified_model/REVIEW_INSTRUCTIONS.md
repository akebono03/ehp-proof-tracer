# コード全文の確認方法

1. `run.ps1 -DryRun` を実行する。
2. 生成された `phase173_r4_r15r17_unified_model/FULL_CHANGED_UNITS.md` を開く。
3. このファイルには変更後の関数全文、新規関数の追加位置、更新した import 全文、新規テスト全文を掲載する。
4. 内容を確認してから通常の `run.ps1` を実行する。通常実行は変更5ファイルをバックアップし、限定 pytest 不合格時には復元する。

DryRun は既存本番コードを書き換えない。レビュー用ファイルは、この新規パッケージディレクトリ内に生成する。
