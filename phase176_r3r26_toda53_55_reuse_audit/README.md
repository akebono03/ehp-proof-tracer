# Phase 176 R3R26: Toda (5.3)/(5.5) Source Reuse Audit

This is a read-only audit package. It checks whether the existing cited double relation from Toda (5.3) and the universal doubled nu-family statement from Toda (5.5) survive source screening for the pi_8^3 public group goal. It records backward candidate counts for the concrete nu_5 double relation. It does not infer the quadruple relation or claim completion of the target group proof.

Run `run.ps1 -DryRun` followed by `run.ps1` from PowerShell after extracting the archive into the repository root. It runs only focused pytest cases, never the full suite. Results are written to `%LOCALAPPDATA%\EHPProofTracerAudit\phase176_r3r26_toda53_55_reuse_audit\report.json`.

No existing production source is modified. No new mathematics or source-level GIVEN is registered. The audit deliberately distinguishes a source present in the original registry from one admitted by source-first screening for the current root.
