# R15R17-R3R5 ブラウザ実表示確認

プロジェクトの通常の Web 起動手順で Flask アプリを起動し、Group query の Narrative を確認する。以下は手動確認の対象であり、この ZIP の HTTP 監査ではブラウザの MathJax や画面レイアウトは実行していない。

- `n=4, k=8`: `使用する結果` が1か所、Proposition 4.4 / DB prior 2件 / Lemma 5.4、`確認済み ProofStep` の抽象群同型 `π₁₂⁴ ≅ ℤ/2`、未解決 Goal が1行に集約され内部3件と明記、記名生成元の証明は未完成。
- `n=4, k=9`: 単一 Reference、抽象群の直和構造の推論、未解決 Goal が1行に集約され内部2件と明記。
- `n=5, k=3`: 未完成・抽象群証明書なし。空の参照一覧をそのまま示し、存在しない ProofStep を表示しない。未解決 Goal は内部3件の集約。
- `n=4, k=4`: 完成証明のまま、Reference と証明本文が表示され、未解決 Goal はない。

すべての通常経路で、独立の `検証済みの途中経過`、`検証済み証明木の Reference`、`証明済みの抽象群構造` の見出しが二重に増えていないことを確認する。数式が MathJax で正常表示されるかも確認する。

この確認を終えた場合は、どの群を表示したか、見出しと数式が見えたかを実測結果として記録する。確認していない場合に `ブラウザ表示 PASS` と記録しない。
