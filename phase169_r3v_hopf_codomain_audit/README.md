# Phase 169 R3V — Hopf Codomain Source Audit

This is a **read-only** diagnostic package for the public π₅³ proof.
It checks whether the previously cited Proposition 5.1 can specialize to
`π₆⁵ = Z/2{η₅}` under the actual screened proof context, and whether this
fact is already a premise of the Hopf-surjectivity proof step.

The audit reports source multiplicity, publication order, the existing
specialization provider, and the result of a real backward-search attempt.
No mathematical assertions or proof steps are fabricated.

From the repository root, run `powershell -ExecutionPolicy Bypass -File .\phase169_r3v_hopf_codomain_audit\run.ps1`.
The full test suite is deliberately not run.
