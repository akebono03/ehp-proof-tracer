# Phase 165 R52-R19: Registered Proof-Use Policy

Adds an opt-in, read-only binding between the existing typed components of Toda Proposition 5.1 and the R18 proof-use order. It neither changes publication order nor certifies unverified source assertions. The shared search accepts `proof_use_order="registered"`; when no matching registered target is present, the existing R16 constraints apply unchanged.

Extract the ZIP into the repository root and run `run.ps1` from PowerShell. Run only targeted pytest; do not run the full test suite before Phase 165 closure.
