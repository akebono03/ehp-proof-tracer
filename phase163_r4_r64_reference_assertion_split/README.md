# Phase 163 R4-R64 — Reference and Assertion Split Proposal

This is a read-only editorial audit of the sixteen unnumbered definition candidates collected in R4-R63.

## Inputs and run

Run `run.ps1` in Windows PowerShell after extracting this ZIP at the project root. The runner reads `phase163_r4_r63_output/source_boundaries.json` and executes only the ten focused pytest cases. Output is written to `phase163_r4_r64_output/`.

The proposal contains sixteen provisional Reference groupings and twenty-one provisional Assertion components. Editorial keys are *not* stable Statement IDs. Source spans, statement boundaries, subject names, scope, and mathematical meanings remain unverified. No production code, IDs, or proof search paths are changed. Do not treat the results as registration approval.

The three output files are `split_proposals.json`, `split_proposals.csv`, and `report.md`. A full test suite is deliberately not run.
