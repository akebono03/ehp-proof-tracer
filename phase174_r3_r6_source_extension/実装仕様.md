## 数学的な依存関係

Toda (4.8) の偶数 $n$・$\Delta(\iota_{2n-1})=0$ という条件の下、$E^2$ の単射性と指数2の商群を推論する。Todo (5.5) ではなく **Toda (5.5)** の一般式 $2\nu_n=E^{n-3}\nu'$ （$n\ge5$）を引用し、既存の $\nu$ 族の定義から具体的な二倍関係を推論する。

新たに GIVEN とするのは検証された**一般命題2件だけ**で、$\pi_8^5=\mathbb Z/8\{\nu_5\}$、$2\nu_5=E^2\nu'$、$E^2$ の単射性、既存群 $\pi_6^3$ は GIVEN としない。既存の Typed Proof Search から取得する。

$\nu'$ の HyoujiGen 表記と文献表記の対応は `same_registered_group_presentation` による型付き ID 検証を使い、名前の一致だけでは受け入れない。
