# Phase 173 R4-R7 — source-first 型付き Toda (5.6) 推論規則の単体導入

## 監査目的

R4-R6 で $\pi_8^4,\pi_9^4,\pi_{10}^4$ の型付き生成元の対応と Proposition 4.4 の source-first 利用可能性が確認された。今回の作業では、独立した型付き推論規則を**公開経路へ接続しない形**で実装し、四つの前提 Goal を通常の Backward Proof Search（後ろ向き証明探索）に解決させる。

一般同型は次のとおり。

$$
\pi_{i-1}^{3}\oplus\pi_i^{7}\cong\pi_i^4,\qquad
(\alpha,\beta)\mapsto E\alpha+\nu_4\circ\beta\quad (i=8,9,10).
$$

## 追加ファイル・関数

- `phase173_r4_r7_source_first_rule/rule.py`：`checked_inputs`、`source_first_toda56_rule`、`expand_source_first_toda56`。3群以外と既存 $\pi_7^4$ は拒否する。
- `phase173_r4_r7_source_first_rule/source.py`：`screened_source_first_context`。既存の `_validated_archive` と publication metadata を利用して、検証済み Lemma 5.4 を独立の source-first コンテキストへ登録する。登録先はメモリ上の複製のみ。
- `phase173_r4_r7_source_first_rule/audit.py`：`git`、`preflight`、`inspect_live`、`write_report`、`run`、`main`。独立探索の実測を記録する。
- `phase173_r4_r7_source_first_rule/tests/test_rule.py`：既存型を使用する新規テスト11件（parametrize 展開を含む実行件数は増える）。
- `run.ps1`、`README.md`、`監査計画.md`、`__init__.py` を新規追加。既存ファイル・import・公開 API は変更しない。

## 信頼性の条件

1. `develop` HEAD と重要な Git blob を必ず検証する。変更のある作業ツリーを拒否する。
2. 原文検証済み Lemma 5.4 の出典情報だけを再利用し、目的群の publication position を付与しない。
3. Proposition 4.4 を source-first の独立した GIVEN として採用し、Hopf 等式そのものは **INFERENCE（導出）** を必須にする。
4. 先行の二群は既存 `admitted_db_step` と `verified_db_step` の検査を通す。これらは既証明命題と混同しない。
5. $\eta_7$ の二表記だけは既存の厳格な表記照合で許す。次元、添字、群位数、因子数に差があれば拒否する。
6. 結論そのものは引用葉にしない。新規規則で証明できた場合も、独立実験と公開 Web 証明を混同しない。
7. $\pi_7^4$ の既存公開証明を回帰テストする。全体 pytest は Phase 173 の終了時にのみ実施する。

## 実行と完了条件

`run.ps1 -DryRun` のあと `run.ps1` を実行する。限定 pytest、前提四件をもつ推論候補の個数、独立探索の成否、`TRACKED_UNCHANGED=True`、既存 $\pi_7^4$ の回帰 PASS を確認する。

`OBSERVATION_COMPLETE` は監査を完走したことだけを示す。`ROOT_CERTIFIED=True` は独立探索における検証であり、公開 UI の完成とは別である。失敗の場合も `audit.json` に原因を残し、R4-R8 で必要な最小限の修正を行う。
