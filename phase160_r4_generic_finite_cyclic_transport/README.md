- Add one generic finite-cyclic transport inference rule.
- Reuse the canonical Toda (4.5) isomorphism produced by Phase 160-R3.
- Preserve the finite cyclic order.
- Represent the target generator as the iterated suspension of the source generator.
- Accept both a concrete canonical source group and the structural `n + k` source form used by Toda (4.5).
- Do not normalize the transported generator to an eta, nu, sigma, or other named family.
- Do not replace the existing Phase 53 or Phase 75 family-specific rules yet.

- Do not change public Narrative.
