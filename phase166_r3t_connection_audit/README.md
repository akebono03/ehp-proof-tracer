# Phase 166 R3-T Connection Audit

Read-only runtime diagnostics for the existing registered-assertion screening and Toda (4.5) transport route for pi_5^4. Install this directory at the root of the user's EHP Proof Tracer checkout and run `run.ps1` from PowerShell. This package does not modify any existing production module. `audit_result.json` is generated locally and includes target assertion IDs, predecessor availability, and transport proposals. Focused tests only; no full-suite pytest.
