# Phase 171 R2J-R2 R1 — HEAD 固定チェック修正

## 原因

R2J-R2 インストーラーの許可 HEAD が `176766a70841853039b8efaac0a8661eac22686d` 一つだけであり、R2J-R1 監査コミット `d172a8a7b0d50f56509f30287aded1b304c7d6a2` を拒否していた。
GitHub `develop` で後者のコミットの変更一覧を確認し、`phase165_r52_r9_shared_math.py` は変更されていない。監査対象の Git blob は `be8824391358d9295ab950e42b7dee5cf34d15a8` で一致した。

## 修正内容

R2J-R2 のインストーラーだけを修正し、上記2つの HEAD を許可する。さらにインストール前に Git が示す追跡済み本番ファイルの blob SHA を照合する。既存のローカル追跡差分・R2I フックの消失・予期せぬ HEAD は従来どおり拒否する。

新規回帰テスト6件を限定 pytest に追加し、2つの HEAD の受理、異なる blob の拒否、未確認 HEAD の拒否、追跡差分の拒否、二重インストールの安全性を検査する。

## 数学的境界

数学的推論コード・R2I 証明・Proposition 5.3 の出典・EHP 規則を変更しない。R2J-R2 の実装と監査は元の ZIP と同一。本番実行時の pytest と証明木監査はユーザー環境で未実施。全体 pytest は Phase 171 終了まで実行しない。

## 実行方法

この ZIP をリポジトリ直下へ `Expand-Archive -Force` で展開すると、R2J-R2 フォルダ内のインストーラーと実行スクリプトが置き換わる。展開時に本番コードには触れない。`run.ps1 -DryRun` で事前確認し、成功したら `run.ps1` を実行する。失敗時の復元処理は維持する。
