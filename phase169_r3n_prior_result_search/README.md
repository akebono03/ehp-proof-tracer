# Phase 169 R3N — Source-Positioned Prior DB Result Aliases

This package connects an already screened, earlier fixed literature group result to an equivalent registered generator presentation during typed backward search. It never searches, stores, replays or requires the proof of the earlier group. It creates an inference step for the presentation identity, **not** a fabricated GIVEN statement.

The source's typed group relation and its reference position must be unambiguous. The R3M prior-result catalog and the existing HyoujiGen generator-ID equivalence are both required. A missing screened fixed-source link, missing source position, ambiguity, self-citation or unrelated generator fails closed.

This phase does **not** implement the missing stable 2-stem $η^2$ generator normalization for higher targets. A partial result such as $\pi_8^6$ must remain partial if the actual mathematical inference chain is not closed.

Run `run.ps1` from the repository root. The installer writes full replaceable function and module copies into `output/` and backs up the original source. Only focused tests are run.
