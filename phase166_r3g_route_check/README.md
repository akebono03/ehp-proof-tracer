# Phase 166 R3-G route check

This package only inspects the current runtime. It makes no production-code changes.

It checks the actual typed source inputs, Proposition 5.1 group goals, Toda (4.5) registered isomorphism statements, direct stable-transport backward options, and the shared search outcome for pi_5^4.

## Run

Extract `phase166_r3g_route_check.zip` into the repository root, then run `powershell -ExecutionPolicy Bypass -File .\phase166_r3g_route_check\run.ps1` from that root.

Report: `phase166_r3g_route_check/audit_result.json`. Full pytest is not run.
