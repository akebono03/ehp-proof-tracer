# Phase 163 R4-R73 Context Decisions

Read-only source-grounded editorial proposals for a subset of the 203 remaining R72 candidates. Each proposed classification preserves its source excerpt and surrounding context. These proposals are **not** mathematical verification and do not authorize registry entries. No production code is modified.

From the project root, expand the ZIP and execute `powershell -ExecutionPolicy Bypass -File .\phase163_r4_r73_context_decisions\run.ps1`. Run R72 first. The script runs focused pytest and writes JSON, CSV, and Japanese Markdown to `phase163_r4_r73_output`. The full pytest suite is intentionally deferred until Phase completion.
