# Phase 165 R6-2 R4-R7: Canonical Reconciliation Audit

This package compares canonical recursive proof reconstruction of the group goal pi_4^3 against each root expansion and all root expansions together. It makes no production edits and does not grant literature citation rights.

From the repository root, extract the ZIP and run `powershell -ExecutionPolicy Bypass -File .\phase165_r6_2_r4_r7_canonical_reconciliation\run.ps1`.

Results are saved in `audit_output/canonical_reconciliation.json` and `.md`. This is a focused audit, not a full test-suite run.
