# Phase 174 R3-R7-R53: Source-bound kernel premise in public group search

This package installs the previously audited, generic R52 source-bound kernel-domain preference in the **existing public zero-group search branch**. It reuses the ordinary source-screened provider and the existing R35 mathematical inference rule, without adding source facts, direct proof steps, a special-case homotopy group, or a narrative renderer.

## Files

- `provider.py`: generic cited-domain source selection and provider wrapper.
- `install.py`: fail-closed, idempotent whole-function replacement of `search_group_from_registered_goal()` in `phase165_r55_nk_only_goal.py`.
- `source_guard.py`: independently pinned reviewed branch, mathematical blobs, and protected working files.
- `audit.py`: actual public Group query search, six-source ancestry, and common model-backed Web view verification.
- `CHANGED_FUNCTIONS_FULL.py`: **complete updated function**, ready for whole-function replacement; other top-level imports remain unchanged.
- `tests/`: scope, provenance, regression, and public completion checks.
- `run.ps1`: source preflight, guarded installation, audit and **focused** pytest only.

Extract the ZIP directly into the repository root on `develop`, first run `run.ps1 -DryRun`, then `run.ps1`. The installer checks that the working source is either the exact reviewed version or the already installed version. It retains the checkout's line endings.

Completion is claimed only if actual public zero-group search and the existing trust-checked model-backed Web entry succeed; HTTP routing is deliberately not claimed. Full-suite pytest is deferred until the end of Phase 174.
