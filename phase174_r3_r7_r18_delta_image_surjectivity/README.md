# Phase 174 R3-R7-R18: Delta Image Surjectivity Frontier

This package defines and audits **one isolated general inference**: if a well-typed EHP Delta map has a separately proved free-cyclic codomain generated by `g`, and its image is separately proved to be the same free-cyclic subgroup generated by exactly `g`, then Delta is surjective.

Neither premise is inferred from the displayed group name, nor is a proof step, source leaf, or result inserted. The proof remains incomplete and the public provider is **not modified** in R18.

Extract this package into the repository root, with the existing Phase 174 R17 changes available. Use PowerShell to run `phase174_r3_r7_r18_delta_image_surjectivity/run.ps1` first with `-DryRun` and then normally. The script checks the reviewed GitHub develop lineage, source file blobs, previous audit reports, existing focused tests and a live public frontier. It never runs the full test suite, resets the repository, or edits tracked files.

The R18 gate documents an isolated candidate and unresolved obligations; it does **not** certify surjectivity or establish `pi_12^7 = 0`.
