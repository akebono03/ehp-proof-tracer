## 原因と目的

R9-R3 は $H:\pi_7^3\to\pi_7^5$ の再構成前提が照合器に拒否されたことを報告した。共通探索器は $(k,n)$ 順序で先行する DB 群構造を `GIVEN` として返しうるが、既存の Hopf 全射性規則は群構造と Hopf 像の両方が `INFERENCE` であることを要求している。個々の入力前提のルール種別は R9-R3 の `audit.json` で最終確認する。

## 証明経路

1. R4-R8 の出典付き既存証明木から、唯一の Hopf 全射性推論と、その巡回群前提に用いた Proposition 5.3 を識別。
2. 現在の登録台帳を照合し、出典が一意、先行、FIXED_STATEMENT、`GIVEN` 葉であることを確認。
3. 巡回群前提を `SourceBoundGoal(group, source)` に変換。既存の `reconstruct_registered_goal()` 自体は変更しない。
4. Hopf 全射性の元の推論規則・他方の Hopf 像前提は変えず、再帰探索が群構造を `INFERENCE` として再導出することを確認。
5. 同じ局所 Provider で最終目標 $\pi_6^3=\mathbb Z/4\{\nu'\}$ を探索し、状態と未解決 Goal を JSON に記録。完成した場合のみ信頼境界を検査。
