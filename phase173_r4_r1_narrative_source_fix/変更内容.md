# Phase 173 R4-R1 — コミット後の公開接続を許容する事前検査の修正

## 原因

前回の `run.ps1 -DryRun` はインストーラの 7 件のテストには合格したが、
`RuntimeError: Reviewed search function Git blob changed` で停止した。
現在の GitHub `develop`（確認時 HEAD `8ae8d263ce22b74b1e30bb9b3a349b708521307e`）では、
R4-R1 公開接続がすでに Git にコミットされている。

- 公開接続前：`phase165_r52_r9_shared_math.py` の blob `2718c55789af7f442ac2c086d016d3d6f7ca3133`
- 公開接続後：同ファイルの blob `3e4c5f9c62b04d618f845b0f82d1cb1cacccdf2e`

比較すると、この2版の差分は監査済み公開フックのみである。
旧インストーラは前者の blob だけを許容したため、後者で誤停止した。

## 実装済みと未実装の境界

公開接続が未コミットの場合は従来どおり `public_preflight()` を使用する。
公開接続がコミット済みの場合は、旧版と新版の source blob の完全一致を要求し、
さらに公開フックを除いた内容が監査済み旧版と一致することを Git blob で確認する。
依存ファイル、公開 route、公開 installer、Toda (5.6) ルールにも改変がないことを確認する。

数学的な ProofStep、Reference モデル、出典、他群の探索は変更しない。
インストールに成功した場合のプロダクション変更は以前と同じ
`phase165_r52_r3_web_adapter.py` の `build_partial_web_group_proof_view()` に限定する。
同関数の変更後全文は同梱の `build_partial_web_group_proof_view_FULL.py.txt` に記載。
import の変更はない。
