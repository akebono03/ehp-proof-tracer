## 確定した DB 規約

`Element` は表示元 ID の順序付き合成。最大5因子。
`gen_coe` は生成元を元の一次結合で表す係数。最大12直和成分に合わせた長さ。
`generator` は任意の参考情報であり、空欄はエラーではない。

## 監査範囲

全 CSV 行の ID 照合、合成因子順序、係数の非零位置と符号、零ベクトル、区切り行候補を記録する。
係数位置がどの元に対応するかは、DB 規約のより具体的な根拠が得られるまで推測しない。
`generator` 文字列は判定に使わない。

## 完了条件・次の境界

各行の元 ID と係数情報を失わず出力し、係数位置の意味を捏造しない。
次段階は係数位置と実際の表示元候補の対応を確認し、その後に typed expression への接続を検討する。
全体 pytest は Phase 166 終了時だけ実施する。
