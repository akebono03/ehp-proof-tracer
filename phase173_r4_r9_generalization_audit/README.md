# Phase 173 R4-R9 — Toda (5.6) Generalization Readiness Audit

This package provides a **read-only audit**, not an implementation of the universal proof rule. It verifies the current `develop` source blobs and evaluates six typed group targets, from `pi_7^4` through `pi_12^4`, without promoting database records to mathematical theorems.

The remote GitHub `develop` HEAD must equal `7158a7f544cd7c6750ebdf82a3b946caa980ea04`. Local HEAD may be either this commit or the previous R4-R8 baseline if the single 11-line shared-math modification is still present. All audited working-tree files must match the reviewed GitHub blobs. No reset, checkout, pull, git commit or push is performed.

Extract the ZIP into the repository root. Run `run.ps1 -DryRun` first and `run.ps1` second. The normal run writes only this package's `audit_result.json` and runs four narrowly scoped test files. Add `-IncludePublic` to the normal run to invoke the six real Group queries and Web projections. Public checks are deliberately optional because they can be expensive.

A shape match is not a proof of a generator image. The audit does not declare new completed groups, alter existing providers or modify the public narrative. A Phase 173 closeout and full test suite are explicitly out of scope.
