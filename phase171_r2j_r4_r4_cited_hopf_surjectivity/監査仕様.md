# Phase 171 R2J-R4-R4-R1 — 出典 ID 修正・監査仕様

## エラー再現と原因

R2J-R4-R4 の初回実行では DryRun と限定 pytest 10件は PASS だったが、実際の証明木再構成は `screened_source_link()` の命題検索で停止した。既存 GitHub develop の R4-R1 監査記録では Toda (5.3) の出典 ID は

```text
shared:8:toda:adopted:eq5.3:nu_prime_hopf_relation
```

であり、旧 R4-R4 の照合対象は `toda:adopted:eq5.3:nu_prime_hopf_relation` だった。統合ブリッジの `shared:<index>:` 接頭辞を含まない完全一致のみを要求したことが原因。

## 最小修正

`audit.py` の `screened_source_link()` の ID 条件のみ変更する。登録済みの完全な ID に対する厳密な一致、または `:` 区切りの namespace 接頭辞を許した完全な接尾辞一致を認める。`endswith(assertion_id)` のような任意部分文字列一致は使わない。

`GIVEN`、前提なし、内容と固定命題の一致、Locator、公開順序、候補の一意性の各検査を維持する。外部から偽の `GIVEN` を作らない。新しい型付き数学規則を追加しない。

## 数学的対象

$$
\pi_6^5\cong\mathbb Z/2\{\eta_5\},\qquad H(\nu')=\eta_5
$$

をそれぞれ Proposition 5.1 の出典付き一般命題の特殊化（`INFERENCE`）と Toda (5.3) の出典付き `GIVEN` により接続し、

$$
H:\pi_6^3\longrightarrow\pi_6^5\quad\text{は全射}
$$

を型付き `INFERENCE` として再構成する。
