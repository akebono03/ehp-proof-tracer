# Phase 165 R54 — Explicit typed group-goal Web entry

Add a Web form for an explicitly supplied free cyclic group generated by `eta_n`, using the existing shared typed backward search and the existing partial proof renderer. The goal is not a GIVEN fact and no historical proof is replayed. This first input parser accepts `n >= 2`, `k = 1`, and `eta_n`; it does not claim support for other generator families or group structures.

From the project root, expand the ZIP and execute `powershell -ExecutionPolicy Bypass -File .\phase165_r54_explicit_web_goal\run.ps1`. Restart the Flask server. In **Explicit group proof goal**, enter `n=2`, `k=1`, `eta_2`, and click **Prove specified group goal**. The older **Calculate** button still runs structure discovery and can continue to report an incomplete result. The new form never uses that result as evidence.

The installer backs up `web_app.py` and `templates/index.html`, checks expected anchors, and generates `CHANGED_CODE.md` with the complete updated `create_app()` function and all imports. Only targeted tests run; full pytest is deferred until the Phase boundary.
