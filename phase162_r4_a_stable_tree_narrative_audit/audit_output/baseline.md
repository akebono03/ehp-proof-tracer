# Group proof narrative

## 使用する結果

**[R1] (4.5).**
$E^{n - 3}: \pi_{3 + 1}^{3} \to \pi_{n + 1}^{n}$ は同型写像である.

---

## 証明

$\pi_{5}^{4}$ の群構造を決定する.

$E^{n - 3}\eta_{3} = \eta_{n}$.

$\pi_{4}^{3} = \mathbb{Z}/2\{\eta_{3}\}$.

[R1]より, $\pi_{n + 1}^{n} = \mathbb{Z}/2\{E^{n - 3}\eta_{3}\}$.

$\pi_{n + 1}^{n} = \mathbb{Z}/2\{\eta_{n}\}$.

これより, 以上より, 

$\pi_{5}^{4} = \mathbb{Z}/2\{\eta_{4}\}$.

$\square$
