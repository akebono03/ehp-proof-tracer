# Phase 169 R10E1 — 群構造に依存しない安定輸送

## 目的

有限巡回群専用だった R7 の候補生成に対し、零群、自由巡回群、有限巡回群、有限・自由巡回群の有限直和を共通の型付き輸送規則で扱う機能を追加する。stem ごとの分岐や、系列ごとの推論規則は追加しない。

## 数学的推論

$n\geq k+2$ と $r\geq 1$ であれば、Toda (4.5) は

$$
E^r:\pi_{n+k}^{n}\xrightarrow{\cong}\pi_{n+k+r}^{n+r}
$$

という同型を与える。$G=0$ であれば、同型を通じて目標群も零群となる。$G=\bigoplus_i C_i$ であれば、同型に加え、それぞれの巡回因子の生成元の像 $E^r(\alpha_i)=\beta_i$ を型付き推論で示して同じ表示を移す。

単一の有限巡回群、自由巡回群は直和の成分数が1の場合であり、同一の推論規則で検査する。直和の成分を入れ替えて同じ表示と見なす処理は行わない。位数と自由／有限の別も検査する。`PrimaryComponent` 等、生成元照合が定義されていない成分は拒否する。

## Proof Tree と引用の境界

`generator_images_for_group_transport()` は `GeneratorImage` の **Goal** を構築するだけで、証明は作らない。`general_group_transport_rule()` の前提は、型付きの先行群、導出済み Toda (4.5) 同型、導出済みの全生成元像である。

`expand_prior_general_group_transport()` は、既存の `resolve_prior_group_result()` と掲載順ゲートを優先する。零群には独立した型付き固定命題と掲載順序を必要とする。いずれの場合も DB に結果があるだけでは引用済み `GIVEN` に変換しない。

R7 の有限巡回群経路は、既存 API と完成 Narrative の互換性のため保存する。共通 Provider の入口だけを統一する。
