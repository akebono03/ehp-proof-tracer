# Phase 168 R3-39G-5 全文差分精査

読み取り専用です。`run.ps1` は限定 pytest、R3-39F 固定基準比較、差分精査を実行します。
プロジェクト内の実装コード・固定基準は変更しません。

出力:
- `output/review.md`: 固定基準と現行文章の差分を全文列挙します。
- `output/review.json`: 機械可読の説明アンカー・引用整合性。
- `output/review_bundle.zip`: 上記と3群の current/diff および基準監査 JSON をまとめます。

`review_bundle.zip` をチャットに添付すると、数学的論証内容と順序の残差を確認できます。

**重要:** 数式・文章の完全同等性を自動保証しません。アンカー照合の偽陰性・偽陽性があります。
固定基準の Reference 番号および一覧は固定ではありません。
全体 pytest は実行しません。
