# Phase 162 R4-B2: Concrete Toda (4.5) transport ancestry

This package adds an opt-in constructor for a concrete-target Toda (4.5) inference followed by the existing finite-cyclic transport inference. It relies on the canonical stable base's **actual** `TodaGroupResult` and its existing `ProofStep`.

## Scope

- Does not edit the repository root, presentation, web app, renderer or references.
- Does not assert `E^r eta_base = eta_target` without an existing proof of that equality.
- Produces a group generated by the *iterated suspension* of the base generator; a later step must prove the named-generator normalization and final target equality.
- Supports finite cyclic groups only; other structures are outside R4-B2.

## Run

Extract this archive to the project root and run `run_phase162_r4_b2_concrete_transport.ps1` from PowerShell in that root. This copies one new module and one new test file, and runs focused tests only.
