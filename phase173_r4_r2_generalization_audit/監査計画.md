# Phase 173 R4-R2 一般化不足の監査計画

## 対象

- Toda (5.2) の $\eta_2\circ(-):\pi_i^3\to\pi_i^2$ の逆方向利用状況。
- Toda (5.6) の $\pi_{i-1}^3\oplus\pi_i^7\cong\pi_i^4$ の一般形の公開接続状況。
- $\pi_7^4$ の完成証明の回帰確認。

## CSV 座標の修正（R4-R2 継続）

初回の DryRun は `data/sphere.csv` の第2行（`n=0`, `k=-1`）で `malformed group coordinates` として拒否された。監査対象は $n\ge3$ であるため、既存の Phase 173 R1 監査と同様に、まず $n$ を検査し、$n<3$ の行を除外した後、対象行の $k$ を検証する。対象行の不正座標は引き続き拒否する。これは監査器の入力読取りの修正であり、群の証明や登録データの修正ではない。

## 今回の境界

数学的な推論規則の追加や既存の本番コードの変更は行わない。実行時の未解決 Goal と source-level（ソース上の）制限を独立に記録する。今回の観測だけでは新たな完成証明を宣言しない。

## 判定に必要な検査

1. $n=3$, $k=4,5,6,7$ について公開経路の未解決 Goal、診断、証明・引用・Web 表示を確認する。
2. $n=4$, $k=3,4,5$ について同様に確認し、$(4,3)$ の完成を回帰確認する。
3. Toda (5.2) からの逆輸送において、$n=2$ の既存証明が $n=3$ の同じ群へ依存していないか検証する。
4. Toda (5.6) の一般形では先行群、対角群、Hopf 像、懸垂と合成の生成元等式を検査する。

## 実装変更対象

`phase173_r4_r2_generalization_audit/audit.py` の `registered_pairs()` と関連する限定テストを修正する。`README.md` とこの文書は修正内容を反映した全文を収録する。その他の本番コード・既存テスト・データベースは変更しない。

## テスト・完了条件

- 修正した CSV 読取りが `n<3` に含まれる負の $k$ を適切に除外する。
- $n\ge3$ の不正な $k$ と不正な $n$ は引き続き拒否する。
- `DryRun` が静的監査の前提条件を通過する。
- 通常監査で7群の実際の公開探索結果を取得し、$\pi_7^4$ の回帰確認を実施する。
- 全体 pytest は Phase 173 の終了時だけに実施する。
