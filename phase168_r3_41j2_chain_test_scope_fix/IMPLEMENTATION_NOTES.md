## 原因と修正

Proposition 4.2 の Reference にある一般 EHP 完全列と、証明本文にある具体的 EHP 完全列の双方に `\xrightarrow{\Delta}` がある。既存テストが両者を合計していたため、1件の失敗が発生した。

修正後は `\n証明\n` を境界として本文を抽出し、その中で `\xrightarrow{\Delta}` がちょうど1回であると検証する。Reference 本文は変更しない。

## 安全性

- 元の Renderer とテストが確認した内容に一致しない場合は無変更で停止。

- 変更後の Renderer 関数全文とテスト関数全文、および変更後のファイル全文を ZIP に含める。
- 新しい群別処理、証明探索、Reference 台帳の追加・削除、文献順判定の変更は行わない。
