# Phase 163 R4-R90

This optional adapter integrates the nine R89 source-only assertions into a newly built (or explicitly supplied) unified registry bridge. It does **not** certify mathematics, register permanent semantic IDs, connect to proof search, or alter the default production bridge. It must not be combined with the older R83/R85 eight-assertion path.

Extract this directory at the project root after R89, then run `run.ps1`. It executes only the R90-targeted tests and writes `phase163_r4_r90_output/report.json` and `report.md`.
