Group query

Query the project quantity pi_(n+k)^n (free part plus 2-primary component).

Operation query

Query an existing proof-backed operation fact.

Examples: H(nu_prime), Delta(iota_9), E(nu_5), E(sigma_11)

Generator proof

Replay the known-group proof for one generator.

Examples: sigma_11, nu_prime, nu_5

Generator exploration

Explore where one generator appears in the existing repository.

Examples: nu_prime, nu_5, sigma_11

Generator proof-scope exploration

Explore one generator across recursive proof ancestry.

Examples: nu_prime, sigma_11, eta_999

Applicable theorem / lemma candidates

Explore compact read-only applicability candidates for one generator.

Examples: nu_prime, nu_5, sigma_11

Execute theorem / lemma candidate

Execute an existing qualified target for one generator.

Examples: nu_prime, nu_5, eta_999
