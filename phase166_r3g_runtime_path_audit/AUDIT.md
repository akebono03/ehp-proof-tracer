# Phase 166 R3-G 実行経路監査

## 目的

24件の限定テスト PASS と、Web の $\pi_5^4$ が `generic-partial-proof` である状態との間にある断絶を切り分ける。

## 確認項目

- Toda (4.5) の型付き一般命題の存在
- 共通探索が具体的同型 $E:\pi_4^3\cong\pi_5^4$ に対する特殊化 Goal を生成できるか
- 従来の transport が一般命題だけで候補を生成できるか
- $\pi_4^3$ の群構造と具体的同型をともに渡した場合に候補が生成されるか
- $E\eta_3$ と $\eta_4$ の表示差が残っているか

## 境界

コード修正なし、個別 Adapter なし、新しい数学規則なし、Renderer 変更なし、全体 pytest なし。
この監査の結果だけで数学的証明の完成とは判定しない。
