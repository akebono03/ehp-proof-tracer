# Phase 174 R3-R6-R4R1 実装仕様

## 不具合

R4 の適用は成功したが、46 件の限定テストのうち 1 件で、公開証明 Narrative 内の Toda (4.8) の一般命題本文が見つからなかった。R4 の `project_reference_bodies()` は assertion ID を受け取れば正しく表示する。問題は、公開モデルで Reference の見出しと assertion-ID から得られる本文が必ずしも一致して結び付かない点にある。

## 方針

従来の共通 Reference 投影は、登録済み assertion ID が欠ける場合、引用済み GIVEN ProofStep を調べる fallback を Lemma 5.4 についてのみ用意していた。既存の同一経路を、型付き Toda (4.8) と (5.5) の一般命題へ拡張する。

引用見出しのみから数学的事実を導かない。候補は実際に同じ Reference へ結び付いた ProofStep であり、(1) GIVEN、(2) 前提なし、(3) 正確な一般命題型と値、(4) 検証済み source rule 名、(5) 同一 source locator、(6) Toda テキストと文献登場順の照合、のすべてを満たす場合のみ本文を表示する。
