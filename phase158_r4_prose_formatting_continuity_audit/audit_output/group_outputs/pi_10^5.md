# Group proof narrative

## 証明対象

\[
\pi_{10}^{5} = \mathbb{Z}/2\{\nu_{5}\eta_{8}\eta_{9}\}
\]

を示す.

## 使用する結果

**[R1] Proposition 5.3.**
$\pi_{4}^{2} = \mathbb{Z}/2\{\eta_{2}^{2}\}$, $\pi_{5}^{3} = \mathbb{Z}/2\{\eta_{3}^{2}\}$, $\pi_{6}^{4} = \mathbb{Z}/2\{\eta_{4}^{2}\}$, $\pi_{n + 2}^{n} = \mathbb{Z}/2\{\eta_{n}\eta_{n + 1}\}$, $n \ge 5$ が成り立つ.
**[R2] Proposition 5.8.**
$\Delta\left(\eta_{9}\right) = E\nu'\eta_{7}$
$\pi_{8}^{4} = \mathbb{Z}/2\{\nu_{4}\eta_{7}\} \oplus \mathbb{Z}/2\{E\nu'\eta_{7}\}$

---

## 証明

まず, $\nu_{4}$ の分解を用いる.
また, $\pi_{8}^{3} = \mathbb{Z}/2\{\nu'\eta_{6}^{2}\}$を用いる.
また, [R1]を用いる.
これらから, $E\nu'\eta_{6}^{2} = E\nu'\eta_{7}^{2}$を得る.
これらから, $\pi_{9}^{4} = \mathbb{Z}/2\{\nu_{4}\eta_{7}^{2}\} \oplus \mathbb{Z}/2\{E\nu'\eta_{7}^{2}\}$を得る.
まず, [R2]を用いる.
これらから, $\Delta\left(\eta_{9}^{2}\right) = E\nu'\eta_{7}^{2}$を得る.
また, すでに得た[R1]を用いる.
まず, $\pi_{11}^{9} \xrightarrow{\Delta} \pi_{9}^{4} \xrightarrow{E} \pi_{10}^{5}$を用いる.
このことから, $\pi_{11}^{9} \xrightarrow{Δ} \pi_{9}^{4} \xrightarrow{E} \pi_{10}^{5}$ は完全である.
また, [R2]を用いる.
さらに, $\pi_{3}^{2} = \mathbb{Z}\{\eta_{2}\}$, $H\left(\eta_{2}\right) = \iota_{3}$, $\Delta\left(\iota_{5}\right) = \pm 2\eta_{2}$, $\pi_{n + 1}^{n} = \mathbb{Z}/2\{\eta_{n}\}$ が成り立つ.
これらから, $\Delta: \pi_{10}^{9} \to \pi_{8}^{4}$ は単射である.
まず, $\pi_{10}^{5} \xrightarrow{H} \pi_{10}^{9} \xrightarrow{\Delta} \pi_{8}^{4}$を用いる.
このことから, $\pi_{10}^{5} \xrightarrow{H} \pi_{10}^{9} \xrightarrow{Δ} \pi_{8}^{4}$ は完全である.
これらから, $H: \pi_{10}^{5} \to \pi_{10}^{9}$ は零写像である.
まず, $\pi_{9}^{4} \xrightarrow{E} \pi_{10}^{5} \xrightarrow{H} \pi_{10}^{9}$を用いる.
このことから, $\pi_{9}^{4} \xrightarrow{E} \pi_{10}^{5} \xrightarrow{H} \pi_{10}^{9}$ は完全である.
これらから, $E: \pi_{9}^{4} \to \pi_{10}^{5}$ は全射である.
これらから, $E\nu_{4}\eta_{7} = \nu_{5}\eta_{8}$を得る.
これらから, $E\nu_{4}\eta_{7}^{2} = \nu_{5}\eta_{8}^{2}$を得る.

したがって, $\pi_{10}^{5} = \mathbb{Z}/2\{\nu_{5}\eta_{8}^{2}\}$を得る.

□
