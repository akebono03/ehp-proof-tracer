# Phase 168 R3-39C source-leaf diagnostic

A read-only analysis of mixed direct and generic Toda (5.1) assertions in the actual shared typed bridge. The tool lists directly adopted facts, available symbolic general sources, and source leaves without a symbolic replacement. It does not rewrite proof facts or alter the project. The JSON report is written under `output/`.

Run `run.ps1` from an extracted package in the repository root. Only two focused pytest cases run. The full suite is deferred to the end of Phase 168.
