# Phase 171 R2J-R4-R9-R17 監査仕様

## 背景と目的

R15 では、16個の相異なる未解決 Goal が観測された。15個は Provider に候補があり、1個は存在しない懸垂同型性 $E:\pi_5^2\to\pi_6^3$ を要求するため、追加してはならない。

R16 では次の4件について、共通探索器が独立した型付き証明木を構築できることを確認した。

- $H:\pi_7^3\to\pi_7^5$ の全射性
- $H:\pi_6^3\to\pi_6^5$ の全射性
- $\Delta:\pi_7^5\to\pi_5^2$ がゼロであること
- $E:\pi_5^2\to\pi_6^3$ の単射性

R17 は、R16 の screened context（審査済み引用文献集合）と通常公開探索が実際に使用した context を比較し、同じ Goal を同じ Canonical Resolver（共通再帰探索器）で独立に再探索する。これにより、出典集合の差と active proof path（探索中の依存経路）の差を分離する。

## 検証

両方の context について、上記4件に加えて、EHP short exact sequence（短完全列）、$|\pi_6^3|=4$、文献で特定した生成元の位数4、cyclic structure（巡回群構造）の4件を独立照会する。

各 Goal は「通常の共通探索器がその context で証明できるか」を調べるものであり、先に証明できた Goal の ProofStep を別の探索へ渡さない。得られた独立証明も元の公開探索を `complete` に変更しない。

`source_comparison` では ProofStepLink に紐づく FIXED_STATEMENT の ID を比較する。`classification` は探索原因の暫定分類であり、単独の証明成功から公開 Root の成功を宣言しない。

### 判定

- `PUBLIC_CONTEXT_MAP_DISAGREEMENT`：R16 側では証明できる EHP Map Goal が公開 context では失敗する。引用文献の一致と経路を監査する。
- `SHORT_EXACT_COMPOSITION_MISSING`：Map Goal が全て証明できても短完全列は閉じない。
- `CARDINALITY_COMPOSITION_MISSING`：短完全列が証明できても位数4が閉じない。
- `ELEMENT_ORDER_COMPOSITION_MISSING`：位数4まで証明できても生成元の位数が閉じない。
- `CYCLIC_STRUCTURE_COMPOSITION_MISSING`：位数と元の位数が独立に証明できても巡回構造が閉じない。
- `ROOT_PATH_DEPENDENT_DESPITE_INDEPENDENT_SUBGOALS`：全ての対象 Goal が独立に証明できても公開 Root が閉じない。active stack や組立経路の監査が必要。

## 完了条件と次段階

完了条件は、限定 pytest 6件 PASS、`audit.json` 出力、追跡中の既存ソースの差分なし、新規 GIVEN 0件、未証明 Goal を勝手に認定しないことである。

R18 以降の実装は R17 の実測結果を踏まえて別途決定する。成立しない $E$ の同型性、証明の非一意性の握り潰し、完成木の輸入、引用境界の緩和を含めない。Phase 終了前に全体 pytest を実行しない。
