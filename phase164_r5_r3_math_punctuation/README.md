# Phase 164 R5-R3: Shared Math Punctuation

This package updates only the shared Web Markdown parser used by the 112-group Narrative view. It keeps punctuation attached to tagged display equations, recognizes third-level Markdown headings, and preserves untagged inline equations. It does not modify proof trees, theorem attribution, math rules, or the Narrative Renderer itself. Run `run.ps1` from the project directory. Only targeted tests run; the full suite is reserved for Phase closure.
