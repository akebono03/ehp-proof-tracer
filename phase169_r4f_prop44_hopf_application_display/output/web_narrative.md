$\pi_i^n=0\quad(i<n)$.

**[R5] η 系列の定義（Chapter V, i）.**

$n\ge 2$ に対し, $\eta_n=E^{n-2}\eta_2$ と定義する.

証明

$\pi_{6}^{4}$の群構造を決定する.

[R1]より, $\pi_{5}^{3} = \mathbb{Z}/2\{\eta_{3}^{2}\}$.

$n=4$ の Hopf fibration $h:S^7\to S^4$ により, $\alpha=h\in\pi_7^4$, $H(\alpha)=\pm\iota_7$ と取れる. [R2]を $(n,i)=(4,6)$ に適用できる.

[R2]より, $E: \pi_{5}^{3}\to \pi_{6}^{4}$ は単射.

[R3]より, $\pi_{5}^{3} \xrightarrow{E} \pi_{6}^{4} \xrightarrow{H} \pi_{6}^{7}$ は完全.

[R4]より, $\pi_{6}^{7} = 0$.

完全性より, $E: \pi_{5}^{3}\to \pi_{6}^{4}$ は全射.

単射性と全射性より, $E: \pi_{5}^{3}\to \pi_{6}^{4}$ は同型.

[R5]より, $E(\eta_{3}^{2})=\eta_{4}^{2}$.

以上より, $\pi_{6}^{4} = \mathbb{Z}/2\{\eta_{4}^{2}\}$.
