# Phase 175 R4R12R13R3 — Conditional Delta/E Public Provider

This package connects the existing, isolated R13R2 mathematical rules to the shared recursive proof search. It introduces **no new mathematical inference rule**, GIVEN statement, completed homotopy group, group-specific narrative, or saved proof.

The EHP suspension-surjectivity branch requires an independently proved Delta-injectivity result and two separately proved exactness windows. The Delta-injectivity branch requires a screened citation of Toda (5.8), a proved free-cyclic presentation of the source, and a proved direct-sum presentation of the target. Database results and typed candidate expressions are **not** promoted to evidence.

The existing alternative E-surjectivity branch using a zero Hopf codomain is retained, not removed. That branch is not a valid proof for the present diagonal group. This package does not alter the renderer or assert completeness of π₉⁵.

Requirements: repository root on `develop`, existing R13R2 package, Python and pytest. Run `run.ps1 -DryRun`, then `run.ps1`. Only focused tests are run; the full test suite is reserved for the end of Phase 175. Installation is limited to one guarded insertion in `shared_expansion_provider` of `phase165_r52_r9_shared_math.py`. The exact complete replacement function is exported to `output/shared_expansion_provider_FULL.py` on each run.

The audit records whether the Toda citation and both conditional candidates are actually available. A missing Delta candidate is explicitly reported as a typed frontier, not claimed as a proof. The recursion, ancestry, and final π₉⁵ proof remain separate subsequent checks.
