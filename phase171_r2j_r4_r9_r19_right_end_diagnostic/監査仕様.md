# Phase 171 R19 — 右端群の証明経路監査

## 対象

R18 で独立証明ができなかった `Relation(pi_6^5, Z/2{eta_5})` を対象に、既存の引用可能な一般命題と Provider の展開候補を比較する。

## 変更対象

既存コードに対する変更はない。新規ファイル `audit.py` の `preflight()`、`classify_right_failure()`、`exact_screened_sources()`、`describe_route()`、`inspect()`、`main()` を追加する。`tests/test_audit.py` には限定テスト7件を追加する。`run.ps1` は DryRun と監査実行を提供する。

## 監査内容

1. R16–R18 のレビュー済みデータと Provider の Git blob を確認する。
2. R18 が採用した右端群の Goal を推論候補から構造的に取り出す。
3. 同一 Goal に一致する先行登録済み `GIVEN` の有無と、Proposition 5.1 の一般形からの特殊化可能性を確認する。
4. `expand_registered_eta_specialization()` と一般的な型付き特殊化および公開共通 Provider の候補を区別する。
5. 同じ共通 Resolver による独立の再構成を監査し、元の例外発生箇所を読む。
6. 入力の ProofStep を共有しない。既存証明木の移植、`GIVEN` の追加、Web 表示の成功宣言を行わない。
