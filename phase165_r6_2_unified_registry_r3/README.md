# Phase 165 R6-2 Unified Registry R3 (source inventory)

A read-only discovery of non-R8 provider connections and top-level `expand_` candidates. It does not automatically register candidates or execute inference rules. Run `run.ps1` from the repository root after extracting the ZIP there. Requires the R1 registry package. Outputs `reports/provider_inventory.json` and `reports/provider_inventory.md`. Only targeted pytest is executed.
