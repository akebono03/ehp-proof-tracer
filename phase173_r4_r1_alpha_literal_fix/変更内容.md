# Phase 173 R4-R1 — Alpha テスト収集衝突の修正

## 監査結果と原因

前回のログで `PHASE173_R4_R1_ALPHA_INSTALL=INSTALLED` が確認された後、限定 pytest の収集時に `import file mismatch` で停止した。原因は次の2ファイルが双方 `test_live.py` という名称であり、pytest の標準 import 動作で `test_live` モジュール名が衝突したことである。

- `phase173_r4_r1_alpha_literal_fix/tests/test_live.py`
- `phase173_r4_r1_narrative_source_fix/tests/test_live.py`

独立した同名ファイル2本を用いた再現試験で、通常の pytest は同じエラーを出し、`--import-mode=importlib` を付けた pytest は `2 passed` になった。

## 今回の変更対象と全文の提供

1. `phase173_r4_r1_alpha_literal_fix/run.ps1`：限定テスト実行コマンドに `--import-mode=importlib` を追加。ファイル全文を ZIP に収録。
2. `phase173_r4_r1_alpha_literal_fix/tests/test_install.py`：`test_focused_runner_isolates_same_named_test_live_modules()` を末尾に追加。新規 import は不要。テストファイル全文を ZIP に収録。
3. `README.md` と `変更内容.md`：全文更新して ZIP に収録。

変更しないもの：`phase173_r4_r1_alpha_literal_fix/install.py`、`phase173_r4_r1_narrative_source_fix/projection.py`、`phase165_r52_r3_web_adapter.py`、証明規則・ProofStep・文献登録。数学的導出は変更しない。
