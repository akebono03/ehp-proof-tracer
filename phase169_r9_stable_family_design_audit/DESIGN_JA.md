# Phase 169 R9 — stable 元の一般系列規則

現在の登録では `HyoujiGen.csv` の `kinds=0` は、系列を表す記号の型付き生成に使用されている。`n` は最小記録次元だが、安定範囲の始点とは限らない。例えば $\eta$（$k=1, n=2$）、$\nu$（$k=3, n=4$）、$\sigma$（$k=7, n=8$）はいずれも最小次元よりも後で安定範囲に入る。

**概念設計**：系列 ID $f$、stem $k_f$、最小次元 $n_0$ を用い、候補 $f_n$ を型付き表現として生成する。$f_{n+r}=E^r f_n$ を証明済みに昇格させるには、系列の懸垂命名規約・引用済み定義に結びつける。`kinds=0` だけで数学的な推論を完成させない。

**群同型**：$n\ge k_f+2$ の場合のみ Toda (4.5) の推論経路を使用する。$n=n_0$ からのすべての懸垂が群同型であるとは推論しない。

**合成元**：$E^r(\eta_4\circ\eta_5)=E^r\eta_4\circ E^r\eta_5=\eta_{4+r}^2$ という一般法則を用いる。逐次 `GeneratorImage` は Proof Tree に保存し、Renderer は証明済み連鎖を一つの式 `E^r(\eta_4^2)=\eta_{4+r}^2` にまとめる。

**3-stem**：現在の監査結果では $\pi_8^5$ が `search_failed` のため、元の同定だけを改善しても $\pi_{10}^7$ の完成とはならない。未解決の根拠を残す。

この ZIP は設計監査専用。既存コード・既存テスト・主要文書を変更しない。全体 pytest は実行しない。
